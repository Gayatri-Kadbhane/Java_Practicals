 Java Practicals

This repository contains my **Java practical programs** created as part of my Computer Engineering coursework.

 📚 About

The practicals cover basic and important Java programming concepts, including:

* Java fundamentals
* Variables and data types
* Operators
* Conditional statements
* Loops
* Arrays
* Strings
* Methods
* Classes and Objects
* Constructors
* Inheritance
* Polymorphism
* Encapsulation
* Exception Handling
* Packages
* File Handling
* Collections
* Other Java programming concepts

Each practical contains the Java source code related to that experiment.

🛠️ Technologies Used

* Java
* JDK
* VS Code / Java IDE
* Command Prompt

▶️ How to Run

1. Install Java JDK.
2. Open the practical folder.
3. Open Command Prompt or VS Code Terminal.
4. Compile the Java program:
javac ProgramName.java
5. Run the program:
java ProgramName

 🎯 Purpose

The purpose of this repository is to practice Java programming concepts and maintain all practical programs in one place for learning and academic reference.
